# Media Kit & Catalogo — Estética & Skincare Facial

Um Media Kit interativo em formato de **Editorial Book / Apresentação de Slides**, desenvolvido especialmente para profissionais e clínicas da área de estética, saúde da pele e limpeza facial. O projeto foi projetado para ser utilizado como página de destino na **bio do Instagram**, apresentando serviços, tabela de preços, métricas, galeria interativa de antes/depois e canais diretos de contato/agendamento.

![Preview do Projeto](estetica.jfif)

---

## Principais Funcionalidades

- **Layout Estilo Revista/Book**: Navegação por páginas em formato slide com transições suaves.
- **Mobile-First & Touch Swipe**: Projetado nativamente para telas de smartphones com suporte a gestos de arrastar (*swipe*).
- **Slider Interativo Antes & Depois**: Comparador de fotos antes e depois do procedimento em tempo real.
- **Tabela de Serviços & Preços**: Apresentação clara de procedimentos estéticos e pacotes para publicidade.
- **Métricas & Demografia**: Exibição visual de engajamento, número de seguidores e perfil do público.
- **Agendamento Rápido via WhatsApp**: Links e botões diretos integrados com o WhatsApp e atalho para cópia de e-mail com notificação Toast.
- **Navegação Acessível**: Suporte a teclado (setas para esquerda/direita) e barra de abas superior.

## Como Executar o Projeto

1. **Clonar o Repositório**:
```bash
git clone [https://github.com/seu-usuario/media-kit-skincare.git](https://github.com/seu-usuario/media-kit-skincare.git)

```


2. **Acessar a Pasta do Projeto**:
```bash
cd media-kit-skincare

```


3. **Executar a Aplicação**:
* Como o projeto é construído em código nativo (*vanilla web*), basta abrir o arquivo `index.html` em qualquer navegador ou utilizar a extensão **Live Server** no VS Code.



---

## Como Utilizar no Instagram (Bio)

1. Faça o deploy dos arquivos em uma plataforma gratuita de hospedagem como:
* [GitHub Pages](https://www.google.com/search?q=https://pages.github.com/&utm_source=gemini)
* [Vercel](https://www.google.com/search?q=https://vercel.com/&utm_source=gemini)
* [Netlify](https://www.google.com/search?q=https://www.netlify.com/&utm_source=gemini)


2. Copie o URL gerado após o deploy.
3. Cole o link no campo **Site / Link na Bio** do perfil do Instagram.
